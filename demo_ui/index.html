      the argument
      
      
      Facts in. Judgment out. Code that doesn’t grow per role.
      
      
      
        The ontology holds what is true, legal and possible — never the choice. The agent’s
        identity, the routes, the constraints all render from it. Adding a role costs no new code.
        That’s the difference between an agent that looks grounded and one that is.
